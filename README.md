# ชุดเกมการเรียนรู้สำหรับเด็กปฐมวัย (Preschool Educational Games Suite)

เว็บแอปพลิเคชันสื่อการเรียนรู้เชิงปฏิสัมพันธ์สำหรับเด็กระดับปฐมวัย (อนุบาล 1 – 3) สอดคล้องกับหลักสูตรการศึกษาปฐมวัย ออกแบบเพื่อพัฒนาการด้านร่างกาย อารมณ์ จิตใจ สังคม และสติปัญญา

---

## 🎮 รายชื่อเกมทั้งหมด (11 เกม)

1. **เกมจับคู่สถานที่สำคัญอาเซียน** (`asean-landmarks.html`) - เรียนรู้ 11 ประเทศสมาชิกอาเซียน ธงชาติ และสถานที่สำคัญ
2. **เกมเรียงขนาดอาชีพ** (`size-sorting.html`) - เปรียบเทียบขนาด เล็ก >> ใหญ่ และ ใหญ่ >> เล็ก 8 อาชีพ
3. **เกมต่อภาพจิ๊กซอว์อาเซียน** (`jigsaw.html`) - ต่อชิ้นส่วนจิ๊กซอว์สถานที่สำคัญอาเซียน 8 ภาพ
4. **เกมจับคู่ตัวเลขอารบิกกับตัวเลขไทย** (`number-matching.html`) - ฝึกนับและจับคู่ตัวเลข ๑ - ๑๐
5. **เกมจับคู่เครื่องแต่งกายกับสถานที่ทำงาน** (`occupation-matching.html`) - จับคู่อุปกรณ์และชุดทำงาน 8 อาชีพ
6. **เกมต่อภาพจิ๊กซอว์อาชีพ** (`career-jigsaw.html`) - ต่อภาพอาชีพในฝัน 13 อาชีพ
7. **เกมเรียงขนาดอาชีพในฝัน** (`career-size-sorting.html`) - เปรียบเทียบขนาด เล็ก-ใหญ่ 17 อาชีพ
8. **เกมเรียงลำดับเหตุการณ์** (`event-sequencing.html`) - ลำดับเหตุการณ์ก่อน-หลัง 5 เรื่องราว
9. **เกมเขียนตามรอยเส้นประพยัญชนะไทย** (`thai-tracing.html`) - ฝึกคัดลายมือพยัญชนะไทย ก - ฮ 44 ตัว
10. **เกมเลือกพยัญชนะตรงกับรูป** (`thai-select.html`) - สังเกตภาพแล้วเลือกตัวพยัญชนะที่ถูกต้อง 44 บัตรคำ พร้อมแอนิเมชันไม้หนีบ
11. **เกมจำแนกสิ่งมีชีวิต** (`living-classification.html`) - เรียนรู้วิทยาศาสตร์ปฐมวัย จำแนกสิ่งมีชีวิตและสิ่งไม่มีชีวิต 36 บัตรภาพลงกล่อง 2 กล่อง พร้อมพาเลต 3 ตัวเลือกสุ่มสลับข้างซ้าย-ขวา

## 🎨 มาตรฐานการออกแบบและการพัฒนา

รายละเอียดและข้อกำหนดเชิงลึกสามารถศึกษาได้ที่ [GAME_GUIDELINES.md](GAME_GUIDELINES.md):
- **ภาพพื้นหลัง**: ทุกเกมมีภาพพื้นหลัง 3D การ์ตูนน่ารักเฉพาะเกม (`assets/images/bg_*.jpg`)
- **องค์ประกอบ UI สากล**: ทุกเกมใช้ปุ่มมาตรฐานเดียวกัน ได้แก่ **ปุ่มโฮม**, **ปุ่มเสียง**, และ **ปุ่มรีเฟรช/เริ่มใหม่**
- **ฟอนต์มาตรฐานมีหัว**: ใช้ฟอนต์ไทยมาตรฐานมีหัวสำหรับเด็กอนุบาล
- **การแสดงผล 100% Viewport**: เลย์เอาต์พอดีหน้าจอ ไม่มีแถบเลื่อนบนทุกอุปกรณ์
